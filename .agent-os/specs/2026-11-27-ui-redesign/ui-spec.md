# UI 계약

- 232px 데스크톱 사이드바, 중립 배경·인디고 강조·얇은 테두리. 모바일에서는 기존 메뉴 전환을 유지한다.
- JD 입력, 이력서 입력, 분석 옵션 순서 및 기존 레이블·이벤트를 유지한다. 준비 패널은 기존 사전 검증 결과로 세 단계의 완료 여부를 표시하고 분석 CTA는 한 개만 제공한다. 모바일에서는 입력 아래 패널을 배치한다. 오류와 진행 상태는 기존 계약대로 표시한다.
- 결과 요약은 선택한 JD/ATS 점수를 같은 grid에 배치한다. 성공 결과의 기존 개선 제안과 키워드, 문장 첨삭을 유지하고 임의의 점수나 우선순위를 생성하지 않는다. 내보내기·인쇄·새 분석 동작을 보존한다.
- 장식 아이콘은 SVG로 통일한다. 파일 선택에 가시적 포커스를 제공하고 문구는 한글 단어 단위로 줄바꿈한다. 데이터 안내는 분석 이력에 입력 텍스트가 저장됨을 설명한다.
