- 대상: 인증 user/date quota가 적용되는 `POST /api/analysis-histories`, `/file`, `/{historyId}/retry`; 비인증 `/api/diagnose` preview 제외. 선택 `Idempotency-Key`는 같은 user/key 완료/RUNNING history를 재사용하고 quota/provider를 재실행하지 않으며 retry는 새 분석이다. 초과는 HTTP 429 `AI_QUOTA_EXCEEDED`와 `retryAfter`(초), `limit`, `remaining`, `resetAt` metadata를 반환하고 secret/원문은 넣지 않는다. 입력 50~10,000자·PDF/DOCX 10 MiB 이하, daily limit 기본 20·Gemini timeout 10/30초 설정과 하위 호환을 유지한다.
