# 구현 계획

1. WANTED_URL과 프론트 URL 판별을 추가한다.
2. Wanted 전용 HTML/Next.js 데이터 추출과 종료 상태 검증을 추가한다.
3. 설명 영역 이미지 OCR과 출처별 이미지 allowlist를 연결한다.
4. 분석 snapshot 저장, 이력 출처 표기, 실패·보안 fixture 테스트를 추가한다.
5. 백엔드·프론트 테스트 및 빌드, 컨테이너 smoke 검증을 수행한다.
